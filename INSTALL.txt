EASYDOC UPDATE - INSTALL (shudhu 1 ta line edit lagbe)

1) Ei zip ta Laravel project er main folder e (jekhane artisan, composer.json ache) Extract/Replace korun.
   (Kono existing file overwrite hobe na - shob notun file.)

2) bootstrap/providers.php file khulun, array er bhitore ekta line add korun:

       App\Providers\EasyDocShareServiceProvider::class,

   Example:
       return [
           App\Providers\AppServiceProvider::class,
           App\Providers\EasyDocShareServiceProvider::class,
       ];

3) Terminal (local):
       php artisan migrate
       php artisan optimize:clear
       php artisan route:list --name=prescription

4) GitHub push + cPanel "Deploy HEAD Commit". cPanel e Terminal na thakle phpMyAdmin e:
       ALTER TABLE prescriptions ADD COLUMN share_token VARCHAR(64) NULL;
       ALTER TABLE prescriptions ADD COLUMN shared_at TIMESTAMP NULL;
       CREATE UNIQUE INDEX prescriptions_share_token_unique ON prescriptions(share_token);

Ki hobe:
 - Shob page e stethoscope preloader
 - Doctor er print page e (URL/route name e "print" thakle) nicher bar: Copy link, WhatsApp, SMS, Share, JPG, PDF, Link bondho
 - /p/{token} public page: rugi login charai prescription dekhbe + JPG/PDF download
 - Doctor area (doctor.* route / /doctor/* URL) te phone e drawer sidebar + boro input + sticky save

Jodi ekta kaj na kore:
 - Public page e error: PublicPrescriptionController.php er VIEWS list e apnar print blade er nam din.
 - Sidebar drawer na ashle doctor layout e age:
     <script>window.EDOC_SIDEBAR='.sidebar-class';window.EDOC_MAIN='.main-class';</script>
